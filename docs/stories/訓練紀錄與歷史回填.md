# 訓練紀錄與歷史回填

> **狀態**：已完成（持續維運）

---

## 為什麼需要這個功能？

漸進負荷的關鍵是知道「上次做了多少」。每次重新輸入歷史重量既費時又容易錯。系統要在使用者打開 App 時就能看見上次的重量做為基準，並提供快速微調工具方便往上加重。

---

## 使用者可以做什麼？

- **自動回填**：點到某動作某組時，系統用該動作 `history` 的最新 `{ weight, reps }` 預先帶入（commit `b0a44d2`）
- **快速微調**：重量欄位旁的 + / − 按鈕，預設步進 2kg（可在設定改）
- **完成標記**：點「完成」記錄該組，畫面降低不透明度區分已完成
- **時間戳記**：每組記錄 `completedAt` 時間，供休息通知、訓練總時長使用

### 資料結構

```js
// logs
{ "w1-d0-bp_flat-s0": { weight: 100, reps: 10, done: true, completedAt: 1700000000000 } }

// history (v3)
{ "bp_flat": { weight: 100, reps: 10 } }
```

---

## 備註

- v2 → v3 的遷移：`history[id]` 從單純 `number` 升級為 `{ weight, reps }` 物件，避免次數資訊遺失
- 重量步進在設定面板可改（`weightIncrement`，預設 2）
- 若 history 無紀錄，輸入欄位保持空白
