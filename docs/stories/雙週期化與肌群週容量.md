# 雙週期化與肌群週容量

> **狀態**：已完成（持續維運）

---

## 為什麼需要這個功能？

RP 原則認為訓練量應該在「最小有效（MEV）」到「最大可恢復（MRV）」之間遞增，達到 MRV 後必須減量（deload）讓身體超量恢復。手動計算每週每肌群的目標組數既繁瑣又容易出錯，因此系統以「肌群週容量」為核心，自動分配到 session 與動作。

詳細演算規則見 [spec/initial/PRD.md](../../spec/initial/PRD.md)。

---

## 使用者可以做什麼？

- 10 週為一個大週期，自動切換階段：
  - **W1–W4 肌肥大期**：肌群週容量從 MEV 遞增至 MRV，複合 8–12 下、隔離 10–15 下
  - **W5 減量週**：所有肌群降至 MEV 的 50%
  - **W6–W9 肌力期**：組數鎖定 MEV、重量遞增，複合 3–6 下、隔離 8–10 下
  - **W10 減量週**：同 W5
- 看到每個動作當週的「建議組數 + 建議次數區間」自動算好
- 切換週次即可預覽未來週的菜單

### 肌群週容量配置

```
CHEST:     [12, 14, 16, 18]   // W1(MEV) → W4(MRV)
BACK:      [12, 14, 16, 18]
SIDE_DELT: [8, 10, 12, 14]
REAR_DELT: [8, 9, 10, 12]
TRICEPS:   [8, 9, 10, 12]
BICEPS:    [8, 9, 10, 12]
QUADS:     [4, 4, 4, 4]       // 固定（純維持）
HAMS:      [4, 4, 4, 4]       // 固定（純維持）
```

### 單動作天花板

預設每動作上限 `MAX_SETS_PER_EXERCISE = 4`，避免後期單動作組數爆炸進入垃圾容量區間。

## 備註

- 分配演算法：肌群週目標 → 均分到包含此肌群的 sessions → 再均分到該 session 內動作（**第一個動作拿餘數**）
- 減量週公式：`Math.max(2, Math.floor(MEV * 0.5))`，至少保留 2 組
- 修改 `VOLUME_CONFIG` 後，所有衍生分配會自動重算
