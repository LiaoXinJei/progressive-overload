## 專案背景

**RP FOCUS PRO** 是一款以**手機端**為主要使用情境的漸進式訓練追蹤 PWA。

- **目標用戶**：中高階健身者，每週訓練頻率受限（4 天 / 週），目標明確 — 上肢顯著增長、下肢維持功能
- **核心矛盾**：有限的恢復能力 vs 特定部位極大化
- **解法**：基於 Renaissance Periodization (RP) 的訓練量管理 + 非對稱推拉架構，把下肢容量壓到 MEV、釋放 CNS 資源全力供給上肢
- **技術定位**：純前端 PWA（React + Vite + Tailwind），全狀態存在 `localStorage`，無後端

主要使用者：個人使用者（自己 / 家人 / 朋友），無多人帳號系統。

## 撰寫慣例

- **故事檔名**：用業務名稱命名（中文），不用程式術語
- **狀態標示**：規劃中 / 開發中 / 已完成（持續維運）
- **「相關實作」要列全**：開發完成後務必補上元件 / 函數連結，這份 index 是新人最快找到「哪個功能對應哪段程式碼」的入口
- **計算公式、邊界 case、資料模型**可放在故事的「備註」區塊
