# 訓練課表升級規格 v3 FINAL

> **For agents**: 本文件取代 v1、v2 版本、為最終版本。請依本文件指示變更 `VOLUME_CONFIG`、`MUSCLE_GROUPS`、`WORKOUTS`、`DEFAULT_EXERCISE_LIBRARY` 四個 export、新增 `SUPERSET_PAIRS` 常數、以及調整週排程邏輯。所有變更必須保留 RP 週期化結構（W1–W10、hypertrophy / strength / deload）與既有資料 schema。

---

## 0. 變更歷史與決策摘要

| 版本 | 主要設計 | 否決原因 |
|---|---|---|
| v1 (Path 2) | 5 練、3 上 + 2 腿、雙週輪替 | 上身週量降至 75%、不可接受 |
| v2 (Path 3) | 6 練、4 上 + 2 腿 | 使用者無法 6 練 |
| v2-modified | 5 練、4 上 + 1 腿、無上身腿 accessory | 腿建底太慢（6–10 個月） |
| v2-superset | 5 練、4 上 + 1 腿、superset 救時 | 60 min 限制下 PUSH B 邊緣 |
| **v3 FINAL** | **同 superset 版 + 移除飛鳥動作 + 確認排程** | 採用 |

### v3 最終決議（所有條件）

1. **每週 5 練、每次 60 分鐘上限**
2. **排程**：Mon PUSH A / Tue PULL A / Wed 休 / Thu PUSH B / **Fri PULL B（含腿彎舉 RIR 2–3、不可至力竭）** / Sat LEGS / Sun 休
3. **上身不退步**：除 CHEST 與 TRICEPS 小幅調整外、其餘上身肌群週量目標不變
4. **CHEST 限制只做推類動作**：平板 / 上斜 / 雙槓三大類、移除所有飛鳥（包含繩索飛鳥、啞鈴飛鳥、蝴蝶機、下斜臥推）
5. **腿建底**：QUADS / HAMS / CALVES 進入 Phase 1 build 區間
6. **脊椎友善**：移除所有軸向加壓動作、所有俯身負重動作
7. **Superset 策略**：複合動作直線組、isolation 採 antagonist superset

## 1. 使用者約束（必須遵守、不得復原）

- **每週 5 練、每次 60 分鐘**。
- **脊椎側彎**：絕對禁止以下動作類型——背槓 / 前蹲 / 任何軸向壓肩動作、傳統硬舉、Trap bar 硬舉重量、Good Morning、彎腰負重划船（如 bb_row）、站姿軍式推舉、Walking lunge 背槓、Hack squat（含肩墊機台）、Zercher squat、Pendulum squat（若有肩墊版本）。
- **顳顎關節影響**：訓練設計不得包含咬牙發力或頸部承重動作。Superset 區段心率上升時、UI 可提示「下顎放鬆、鼻吸口呼」。
- **胸只做推類**：平板（flat）、上斜（incline）、雙槓（dips）三大類。**禁止飛鳥所有變化**。

### Superset 執行原則（給 UI 文案）

1. **複合動作一律直線組**：臥推、推舉、引體、划船、腿推、保加利亞、RDL——全程直線組、組間 2–3 分鐘充分休息。
2. **Isolation antagonist superset**：上述清單中的配對、第一動作做完 → 15 秒切換 → 第二動作做完 → 休息 75–90 秒 → 重複下一輪。
3. **設備衝突 fallback**：若兩動作站位過遠或尖峰時段被佔用、改直線組執行、session 時間會超出 60 min 5–10 分鐘、單次可接受。
4. **心率管理**：Superset 段心率會升至 130–160 bpm、注意「下顎放鬆、鼻吸口呼」、避免咬牙加劇 TMJ 張力。
5. **力竭管理**：Superset 中的第一動作 RIR 1–2、第二動作可至 RIR 0–1。

## 14. 設計哲學註記（供 agent 理解、勿改）

### 為何 CHEST 從 18 砍到 12 不會退步

劑量反應曲線（dose-response curve）研究（Schoenfeld & Krieger 2017 整合分析、Baz-Valle 2022 更新）：
- 胸的劑量反應曲線在 10–15 sets/週區段最陡（每組 ROI 最高）
- 15–20 sets/週區段斜率變平
- 20+ sets/週多數人進入 junk volume

使用者原本 W4 跑 18 sets 胸、實際上邊際 ROI 已極低。砍到 12 落在曲線最陡區段、單組成長效率反而提升。

### 為何採「分散高頻」而非「集中腿日」

肌肉肥大的關鍵限制因素為「肌蛋白合成週期啟動次數」、非「單次訓練量」（Damas 2016、Brigatto 2019）。同樣 12 sets/週、分 3 次每次 4 sets 的長肌效應、優於 2 次每次 6 sets。

### 為何 Superset 不影響肥大

Weakley 2020、Realzola 2022 等對照研究顯示：antagonist superset 在總量相等時、肌肥大結果與直線組無顯著差異、且時間節省 35–50%。Antagonist 配對能在 A 動作休息時讓 B 肌群工作、實為「主動休息」、非「無休息」。

### 為何 Fri 腿彎舉強制 RIR 2–3

Isolation 動作至力竭（RIR 0）後肌肉完全恢復需 48–72 小時。Fri 至 Sat 僅 24 小時、若 Fri 腿彎舉至力竭、Sat RDL 第 1–2 組將承受未恢復肌肉、進步速度可能慢 10–15%。RIR 2–3 仍能產生有效肥大訊號（與 RIR 0 差距 < 10%）、但恢復速度快約 50%。
