# 健身房模式（實驗）

> **狀態**：開發中（設定裡的實驗開關，預設關）

---

## 為什麼需要這個功能？

一直盯著組數表格很枯燥。健身房模式把今天的課表變成一間像素風健身房：每個動作一台器材，人物在器材上做動作、休息時喝水，讓組間記錄多一點樂趣，同時不犧牲「組間單手快速記錄」這個核心操作。

---

## 使用者可以做什麼？

- 在設定「一般」打開「健身房模式（實驗）」。存在存檔裡，多視窗同步，重設資料時保留
- 訓練頁變成全螢幕健身房，下面的面板平常收起來只露出把手；往上滑或點把手才拉上來，就是原本的課表（D1–D5、今天進度、這個動作的全部組數）。做組的時候不會跳鍵盤，面板也不會自己打開
- 重量在場景上改：每站旁邊一座槓片架（20 / 10 / 5 / 2.5 / 1.25），點一片就掛上去，點槓鈴或重量旁的「卸」卸下最外面那片。槓鈴類照真的槓片算（空槓 20、EZ 槓 10，兩邊各掛一片，點 10 kg = +20）；啞鈴、插銷器材、自體重點一片只加一片的重量。沒填重量的槓鈴從空槓開始掛
- 次數在場景下排用 − / ＋ 改；沒填也沒上次紀錄時用這週次數區間的下限，畫面上看到的數字就是完成時會記的數字。做完一組、還沒開始下一組前，次數鈕改的是「剛剛」那組
- 組數在場景下排：每組一個圓點（完成綠、這組藍），＋ 加一組；這站做完了換成「下一台」
- 一個動作一台器材，superset 兩台排在隔壁。左右滑、或按兩側箭頭換器材，人物走過去；面板和下面的動作卡跟著換
- 點器材或人物開始這組（人物開始做動作），再點一下完成這組，等於按 ✓。開始後 1 秒內的第二下不算
- 做完一組換到照做順序的下一組，做完一個動作就走到下一台；不照順序做也不會被拉回第一個沒做的動作
- 休息時人物喝水，提示「休息中 0:48 / 1:30」，超過目標站起來準備；完成一組頭上冒愛心，整天做完舉雙手閃星星
- 減少動態效果時不走路、動作停在中間姿勢、沒有流汗愛心星星

## 備註

- 新增動作庫動作時要在 `FAMILY_BY_ID` 加對應，`stations.test.js` 會擋
- 只有場景是像素風，面板、清單、sheet 維持 DESIGN.md 的 Apple 式介面
- 選站用推導（使用者選的站 + 選的當下的目前這組），不用 effect 跟隨：App 每秒更新時間，effect 會一直把使用者拉回去
- 健身房模式不顯示休息膠囊，自動捲動在面板收著時不動作（不然會把面板拉上來蓋住場景）
- 啞鈴用槓片架加重，2 kg 一跳的啞鈴湊不出來（只有 1.25 / 2.5），要拉上面板在清單改。先試用，覺得怪再改成各器材自己的畫法（啞鈴架、配重片插銷）
- 預覽工具：`.impeccable/tools/gym-shots.cjs`（需要 dev server 開在 5199）
