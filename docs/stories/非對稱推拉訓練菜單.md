# 非對稱推拉訓練菜單

> **狀態**：已完成（持續維運）

---

## 為什麼需要這個功能？

中高階健身者一週只有 4 練的時間，傳統 PPL（推/拉/腿）或上下分化會讓下肢累積過多疲勞，影響上肢表現。本菜單把下肢容量壓到 MEV、分散到推拉日，把中樞神經系統的恢復資源全力供給上肢，達成「上肢極大化、下肢功能維持」的目標。

詳細背景見 [spec/非對稱推拉架構/PRD.md](../../spec/非對稱推拉架構/PRD.md)。

---

## 使用者可以做什麼？

- 依照當週 + 當日自動取得對應的訓練菜單（PUSH A / PULL A / PUSH B / PULL B）
- 每個 session 顯示主推、副推、隔離動作以及微量腿訓練
- 每組顯示建議次數區間（依肌肥大期 / 肌力期 / 減量週切換）
- Day 切換、Week 切換皆獨立可控

### 4 天循環

| Day | 菜單 | 核心邏輯 |
|-----|------|---------|
| 0 | PUSH A | 水平推力極大化 + 微量腿前（QUADS） |
| 1 | PULL A | 垂直拉力極大化 + 微量腿後（HAMS） |
| 2 | PUSH B | 垂直推力（純上半身） |
| 3 | PULL B | 水平拉力（純上半身） |
